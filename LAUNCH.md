# 🚀 Запуск Glint в Telegram — 15 минут

Код готов: сервер, база, бот, оплата Telegram Stars, маркет, Кузня, подарки по ссылке, рефералка, сезонный пропуск, админ-команды. Осталось выполнить 4 шага, которые можете сделать только вы.

> 🔒 **Токен бота — это ключ от ваших денег.** Не присылайте его в чат, мне или кому-либо ещё. Он вводится только в шаге 3, в настройках хостинга.

## Шаг 1. Создать бота (2 минуты)
1. Откройте в Telegram **@BotFather** → `/newbot`.
2. Введите имя (например, `Glint Gifts`) и юзернейм на `bot` (например, `GlintGiftsBot`).
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Сохраните его в заметках.

## Шаг 2. Узнать свой Telegram ID (30 секунд)
Напишите **@userinfobot** — он пришлёт ваш `Id` (только цифры). Это `ADMIN_ID`: с ним вам доступны команды `/stats`, `/drop` и `/refund`.

## Шаг 3. Деплой на Render (5 минут)
1. Влейте ветку с кодом в `main` (pull request на GitHub → **Merge**).
2. Зайдите на **render.com** → **Sign in with GitHub**.
3. **New → Blueprint** → выберите репозиторий **Maksiulo** → Render найдёт `render.yaml`.
4. Заполните три поля:
   - `BOT_TOKEN` — токен из шага 1;
   - `ADMIN_ID` — цифры из шага 2;
   - `SUPPORT_CONTACT` — ваш @юзернейм для вопросов по оплате.
5. Нажмите **Apply** и подождите 3–5 минут, пока статус не станет **Live**.

Сервер сам подключит бота: вебхук, кнопку меню «Glint» и команды. Делать это вручную не нужно.

💳 **Старт бесплатный.** Сервер сам себя будит, чтобы не засыпать. Бесплатная база на Render живёт около 30 дней, поэтому, когда пойдут деньги, переключите планы на платные (≈ $13 в месяц): Dashboard → сервис → Settings → Instance Type.

## Шаг 4. Открыть и проверить
1. Откройте своего бота → `/start` → кнопка **«Открыть Glint»**.
2. Купите самый маленький пакет (250 ⭐), чтобы проверить оплату. Вернуть деньги себе можно командой `/refund <ваш_id> <charge_id>`.
3. Напишите боту `/stats`.

**Желательно в BotFather:** `/setuserpic` (аватар), `/setdescription` (описание), а также **Bot Settings → Configure Mini App → Enable**, чтобы в профиле бота появилась кнопка «Открыть».

## Команды владельца (только для ADMIN_ID)

| Команда | Что делает |
|---|---|
| `/stats` | Игроки, оплаты Stars, оборот маркета, прогресс дропа |
| `/drop Название \| модель \| редкость \| цена \| тираж \| часов` | Запустить новый дроп. Пример: `/drop Regalia Gold \| 3 \| 3 \| 1500 \| 100 \| 48` |
| `/refund <user_id> <charge_id>` | Вернуть оплату Stars |

Модели: 0 Nova Orb, 1 Prism, 2 Lovebit, 3 Regalia, 4 Lunetta, 5 Surprise, 6 Ember, 7 Comet.
Редкость: 0 Обычный, 1 Редкий, 2 Эпик, 3 Легенда, 4 Миф.

## Как приходят деньги
Игроки платят **Telegram Stars**, и они копятся на балансе бота. Вывести их можно через **Fragment** в TON, а TON — на биржу. У Telegram есть задержка перед выводом и свой курс. Актуальные условия смотрите в @BotFather → ваш бот → **Balance**.

## Чтобы проект «взорвал» соцсети
Вирусность уже встроена в механику:
- **«Подарить»** — каждый подарок уходит другу ссылкой и приводит нового игрока;
- **рефералка** — 10% от пополнений друга навсегда;
- **вход каждый день** с Эпиком на 7-й день;
- **лимитированные дропы** с таймером.

Что делать вам:
1. **Дроп каждую неделю** по расписанию. Маленький тираж = ажиотаж.
2. **Ролики** (Reels / TikTok / Shorts): открытие редкого подарка, сплав в Кузне, «подарил девушке Мифический подарок». Экран открытия с конфетти специально сделан эффектным для записи.
3. **Коллаборации с Telegram-каналами:** «именной» дроп канала, и канал получает долю.
4. **Розыгрыши:** «репост — шанс получить Легенду», раздаёте подарки со своего аккаунта.

Честно о шансах: никто не гарантирует, что проект «взорвёт». Его делают регулярные дропы и контент, а не только код. Продукт для этого готов.
